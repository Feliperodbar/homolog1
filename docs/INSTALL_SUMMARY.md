# 📦 Automação de Screenshot para Navegadores - Windows

## 🎯 Visão Geral

Este pacote contém uma automação completa para capturar screenshots de navegadores no Windows com um simples clique do mouse esquerdo.

## 📁 Arquivos do Projeto

### Arquivo Principal

- **`screenshot_windows_auto.py`** - Script principal com toda a lógica
  - Classe `BrowserScreenshotCapture` - Gerenciador de capturas
  - Listener global de mouse
  - Detecção automática de navegadores
  - Tratamento robusto de erros

### Configuração

- **`config_screenshot.py`** - Arquivo de configuração (opcional)
  - Presets prontos para uso
  - Customizações avançadas
  - Comentários explicativos
